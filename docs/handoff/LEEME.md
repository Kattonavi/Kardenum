# Paquete de traspaso: Kardenum

Todo lo que se hizo en el chat de diseño, listo para arrancar el código en Claude Code.

## Qué hay aquí

- `BRIEF.md`: el resumen que debe leer Claude Code primero. Stack, rutas, qué maqueta es cada página, reglas y orden de trabajo.
- `docs/`: los 6 documentos del proyecto (plan, SEO, identidad, textos, lista previa y naming).
- `maquetas/`: todas las maquetas como páginas HTML navegables. Abre `maquetas/index.html` en el navegador; los enlaces entre páginas funcionan.
- `marca/kardenum-logo-final.zip`: el logo en SVG, PNG y PDF.

## Cómo usarlo

1. Crea la carpeta del proyecto en tu carpeta madre.
2. Copia este paquete dentro, por ejemplo en `docs/handoff/`.
3. Corre `/nuevo-proyecto` y dile que el contexto está en `docs/handoff/BRIEF.md`.
4. Para el logo, descomprime `marca/kardenum-logo-final.zip` y usa los SVG.
